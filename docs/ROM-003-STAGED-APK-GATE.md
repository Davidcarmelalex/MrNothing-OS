# ROM-003 — staged unsigned launcher integrity gate

Scope: draft-only addition stacked on ROM-002 PR #91, not merged into the authorized development anchor. Upstream shared SKILL.md remains absent/unverified; the local PROJECT-ADAPTER.md governs.

Run `python -m unittest discover -s tests -p test_rom_staged_apk.py -v` and `python -m py_compile scripts/verify_staged_launcher_apk.py tests/test_rom_staged_apk.py` on a clean checkout. Execute the verifier with `--apk`, `--record`, `--provenance`, `--release-manifest`, and `--source-commit` arguments. The JSON record schema is exactly `mrnothing-staged-apk-v1`, with source_commit (40 lowercase hex), apk_sha256, provenance_sha256, release_manifest_sha256 (64 lowercase hex), apk_kind=`launcher`, build_variant=`release`, unsigned=true. Both evidence JSON objects must carry the same source_commit.

The verifier rejects missing, nonregular, symlinked, hard-linked, tampered, malformed, debug, signed-v1-marker and mismatched artifacts; it never downloads, builds, executes, signs, flashes, or installs. ZIP entry checks are structural only. APK Signature Scheme v2/v3 signing blocks are NOT parsed: the unsigned flag is an operator assertion, not cryptographic proof of unsignedness. This must be addressed before any release-grade claim. It does not authenticate the provenance issuer, prove that the APK was compiled from the named commit, independently reproduce the APK, establish licensing, validate Android package identity, or confer flash/release authorization. The source commit and expected digest must be independently pinned by an approved operator; do not trust an attacker-supplied record as an authority. Quiescent private staging required to prevent time-of-check/time-of-use races.

Review gates: independent reviewer must inspect the script and negative controls; require real release manifest/provenance schema mapping and Android apksigner verification of v1/v2/v3/v4 absence before production-grade acceptance. No integration into AOSP staging, CI release workflow, or real APK is claimed. All M1–M8 remain unaccepted.
